# Сравнительный анализ алгоритмов коллаборативной фильтрации с учетом временного контекста для рекомендаций книг

## Описание проекта

Цель работы — провести сравнительный анализ классических и временно́-чувствительных алгоритмов коллаборативной фильтрации для построения рекомендательной системы книг. Эксперименты выполнены на реальном датасете **UCSD Goodreads Book Graph**, содержащем 2.7 миллиона пользовательских оценок.

Реализованы и оценены шесть методов:
- User-Based KNN (косинусное сходство)
- Item-Based KNN (косинусное сходство)
- Экспоненциальное временное затухание оценок
- Линейное временное затухание оценок
- Доверие к недавно активным пользователям
- Метод временного окна (только оценки за последний период)

Качество работы сравнивалось по метрикам RMSE и MAE на общей тестовой выборке.

## Датасет

**UCSD Goodreads Book Graph**   
- Количество оценок: 2 700 000+  
- Данные включают: идентификаторы пользователей и книг, рейтинг (1–5), временную метку.

Перед анализом данные прошли этапы:
- Фильтрация малоактивных пользователей и книг
- Разбиение на тренировочную и тестовую выборки (с сохранением временной структуры)
- Приведение к формату user-item матрицы

## Реализованные алгоритмы

| Алгоритм | Краткое описание |
|----------|------------------|
| **User-Based KNN** | Поиск k ближайших пользователей по косинусному сходству, предсказание как средневзвешенная оценка |
| **Item-Based KNN** | Поиск k ближайших книг по косинусному сходству, предсказание на основе оценок пользователя похожим книгам |
| **Экспоненциальное затухание** | Вес оценки убывает экспоненциально со временем: \( w = e^{-\lambda \cdot \Delta t} \) |
| **Линейное затухание** | Вес оценки линейно убывает со временем до нуля |
| **Доверие к активным пользователям** | Активность пользователя влияет на вес его оценок (чем чаще и недавнее взаимодействия, тем выше доверие) |
| **Временное окно** | Для обучения используются только оценки, попавшие в фиксированный недавний временной интервал |

Все методы построены поверх парадигмы k-ближайших соседей с использованием косинусной меры сходства.

## Метрики качества

- **RMSE** (Root Mean Squared Error) — корень среднеквадратичной ошибки
- **MAE** (Mean Absolute Error) — средняя абсолютная ошибка

Меньшие значения соответствуют более высокой точности предсказания рейтинга.

## Результаты

| Метод | RMSE | MAE |
|-------|------|-----|
| User-Based KNN (базовый) | 2.3609 | – |
| Item-Based KNN (базовый) | 1.4280 | – |
| Линейное временное затухание | – | – |
| Временное окно | – | – |
| **Экспоненциальное временное затухание** | **1.2094** | **0.9239** |
| **Доверие к активным пользователям** | **1.2109** | **0.9268** |

*Таблица может быть дополнена результатами всех методов.*

### Ключевые выводы
1. Временные методы значимо превосходят базовые KNN: RMSE снижается с 1.4280 (Item-Based) до 1.2094 (экспоненциальное затухание).
2. Лучшими оказались **экспоненциальное временное затухание** и **доверие к активным пользователям** (разница между ними в пределах 0.1%).
3. Item-Based подход оказался в **1.65 раза** точнее User-Based (RMSE 1.4280 против 2.3609), что подтверждает его эффективность для разреженных данных книжных рекомендаций.
4. Учет временного контекста (актуальность оценок, активность пользователей) является обязательным для повышения точности рекомендаций.
